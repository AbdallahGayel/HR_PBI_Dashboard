# Corporate HR & Payroll Analytics Dashboard

A comprehensive Business Intelligence solution designed to track, analyze, and visualize workforce metrics and payroll expenditures.

## Core Objectives
* Deliver transparent visibility into payroll growth and operational cost discrepancies.
* Track real-time employee attendance and performance metrics.
* Provide executive stakeholders with a dynamic, highly responsive visual interface for decision-making.

## Tech Stack
* **Visualization:** Power BI, Microsoft Excel
* **Data Modeling:** DAX (Data Analysis Expressions), Power Query
* **Data Source Integration:** SQL Server / Flat Files

## Key Features & Deliverables
* **DAX Optimization:** Developed custom DAX measures to accurately calculate year-over-year payroll growth and isolate cost variances.
* **Interactive Visuals:** Engineered drill-down capabilities allowing management to investigate attendance metrics by department and role.
* **Data Cleaning & Transformation:** Utilized Power Query to standardize inconsistent reporting formats into a clean, dimensional data model.
